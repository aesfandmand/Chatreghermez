# چک‌لیست کارهای نیازمند محیط واقعی (بعد از اتصال به سایت)

قاعده: هر مورد پس از انجام تیک بخورد و نتیجه (موفق/خطا) کنار آن نوشته شود. هیچ کلید یا رمزی در مخزن یا اسناد نوشته نشود.

## الف) پیش از شروع (از مالک)
- [ ] اتصال به سایت در کروم؛ تعیین اینکه سایت **آزمایشی** است (نه زنده) و یک پشتیبان کامل گرفته شده است.
- [ ] نسخهٔ PHP و وردپرس و ویرایش المنتور پرو را بخوانم و ثبت کنم (حداقل PHP ۸٫۱ و وردپرس ۶٫۵).
- [ ] مخزن‌های RUOS و Chatreghermez خصوصی شده باشند.

## ب) نصب و راه‌اندازی
- [ ] آپلود/فعال‌سازی `chatreghermez-commerce`؛ بررسی ساخت ۱۳ جدول با پیشوند `crc_` (نسخهٔ پایگاه‌داده ۵) بدون خطای dbDelta.
- [ ] فعال‌سازی `chatreghermez-media-rental` (پس از commerce)؛ بررسی ۳ جدول.
- [ ] صفحهٔ «دسترسی نقش‌ها»: ماتریس پیش‌فرض را نشان بدهد؛ ادمین همه مجوزها را داشته باشد؛ تغییر یک مجوز در گزارش تغییرات ثبت شود.
- [ ] تنظیمات امن: `crc_gateway`، `crc_zibal_merchant` (کد آزمایشی)، `crc_sms_provider` — فقط از صفحهٔ مدیر، نه از مخزن.
- [ ] مطمئن شوم افزونهٔ ووکامرس در این سایت نیست یا تداخلی ندارد (بررسی تحلیلی قبل از حذف).

## پ) هستهٔ تجارت — سناریوهای پذیرش (GATE-1.6، ۱۲ مورد)
- [ ] ۱ محصول ثابت/پله‌ای/متراژی ← قیمت سرور = دست‌محاسبه؛ ورودی نامعتبر رد شود.
- [ ] ۲ سبد مهمان ← ورود با رمز یک‌بارمصرف ← ادغام سبد.
- [ ] ۳ کد تخفیف: درست، منقضی، تمام‌شده؛ مصرف اتمیک.
- [ ] ۴ سفارش مختلط محصول + خدمات ← دو فاکتور؛ جمع فاکتورها = جمع سفارش.
- [ ] ۵ پرداخت آنلاین آزمایشی زیبال؛ بازگشت دوباره از درگاه پرداخت را دوبار ثبت نکند.
- [ ] ۶ مبلغ نادرست از درگاه ← رد.
- [ ] ۷ پرداخت دستی با کلید تکراری ← فقط یک پرداخت.
- [ ] ۸ چک: صیاد/کد ملی نامعتبر، سررسید بیش از ۴۵ روز در فاکتور خدمات، تأیید حسابدار.
- [ ] ۹ تمدید رزرو: دو بار مجاز، بار سوم رد.
- [ ] ۱۰ نقش‌ها و نشت داده: مشتری سفارش دیگری را نبیند.
- [ ] ۱۱ پیامک رویدادها در صف، ارسال با آداپتور، ۳ تلاش.
- [ ] ۱۲ صفحهٔ محصول و اسکیما برای ترب (قیمت/موجودی در HTML، ارز IRR).
- [ ] مرور مستندات فعلی زیبال و تطبیق `ZibalGateway` (آدرس‌ها، فیلدها، کدهای نتیجه) — اکنون از حافظه است.
- [ ] پیش‌پرداخت ۵٪: چند مبلغ نمونه (۵۸٬۸۸۵٬۹۳۸ ← ۵۹٬۰۰۰٬۰۰۰ و ۳۲٬۴۱۸٬۵۱۴ ← ۳۲٬۵۰۰٬۰۰۰) روی فاکتور اجاره.

## ت) پیشخوان

- [ ] کدهای تخفیف: ساخت، فعال/غیرفعال.
- [ ] ظاهر منوی «چتر قرمز» و ترتیب زیرمنوها.

## ث) اجارهٔ رسانه
- [ ] ساخت یک رسانه نمونه (صفحهٔ مدیریت هنوز نوشته نشده؛ تا آن زمان با ورود مستقیم یا ورود اکسل).
- [ ] تقویم ۱۲ ماهه: رنگ‌ها و «روز باقی‌مانده»؛ قفل هم‌زمان دو کاربر (فقط یکی موفق شود).
- [ ] سفارش اجاره ← فاکتور اجاره جدا به‌تفکیک شهر؛ پیش‌پرداخت ← رزرو ۵ روزه؛ پرداخت کامل ← قطعی.
- [ ] انقضای رزرو (کران ساعتی وردپرس واقعاً اجرا شود؛ در صورت کم‌بازدید بودن سایت WP-Cron واقعی روی هاست تنظیم شود).
- [ ] صف «اطلاع بده»: هر ساعت یک نفر.
- [ ] ورود اکسل مبارکه: تطبیق ستون‌ها، ۶ رقمی بودن کد، ردیف ۲۷ (کد ۱۰۰۶۱۳ ناقص)، نام‌های تکراری برند.

## ج) المنتور و سئو
- [ ] ویجت‌ها (فهرست محصول، کارت، سبد کوچک، سبد، تسویه، حساب کاربری، فهرست رسانه، تقویم) بر پایهٔ REST ساخته و روی صفحهٔ واقعی بررسی شوند.
- [ ] نقشهٔ نشان: کلید فقط در تنظیمات امن؛ هزینهٔ پس از دورهٔ رایگان (حدود ۳۰ آبان ۱۴۰۵) را مالک تأیید کند.

## چ) باز، نیازمند تصمیم مالک
- [ ] انتخاب نهایی درگاه؛ انتخاب سرویس پیامک و آداپتور آن؛ متن نهایی قالب‌های پیامک.
- [ ] متن حقوقی «پیش‌پرداخت غیرقابل‌استرداد» با تأیید حقوقی/حسابدار.
- [ ] آزمون قفل: پس از ۱۵ دقیقه با heartbeat قفل بماند؛ با بستن تب (release/قطع ping) آزاد شود؛ سقف ۳ ساعت.
- [ ] آزمون رزرو: تأیید سپردهٔ ۵٪ درگاه ← رزرو ۵ روزه (یک بار)؛ تمدید فقط با نقش دفتر، دو بار؛ مشتری نتواند.
- [ ] آزمون یادآوری: ۲ روز مانده، پیامک به مشتری + سرپرست + حسابدار (هر کدام شمارهٔ `crc_mobile` داشته باشند)؛ پس از تمدید دوباره یادآوری شود.
- [ ] آزمون قطعی‌سازی: ثبت و تأیید چک‌ها ← قطعی، آزاد نشود.
- [ ] فهرست اصناف و پرسونا برای پروفایل مشتری.
