# Chatreghermez Media Rental — شروع از اینجا

افزونهٔ فاز ۲: اجارهٔ رسانه. **وابسته به `chatreghermez-commerce`** است و فقط یک «نوع خط سفارش» (`media_rental`) روی هستهٔ تجارت ثبت می‌کند؛ سبد، سفارش، فاکتور و پرداخت جدا ندارد.

## قواعد (از تصمیم‌های مالک)
- واحد رزرو = یک رسانه × یک ماه سال مالی (اردیبهشت = ماه ۱ … فروردین = ماه ۱۲).
- رنگ‌ها: آزاد / قفل موقت (۱۵ دقیقه هنگام انتخاب و پرداخت) / رزرو (۵ روز پس از پیش‌پرداخت ۵٪) / قطعی / خاکستری (غیرقابل اجاره).
- قفل ۱۵ دقیقه‌ای فقط برای مرحلهٔ پرداخت نقدی (درگاه) است و از لحظهٔ رفتن به درگاه شمرده می‌شود؛ قطعی شدن و تسویه فقط پس از تأیید پرداخت درگاه.
- مسیر چک: قفل ۱۵ دقیقه‌ای ندارد؛ رزرو ۵ روزه با ثبت چک توسط دفتر شروع می‌شود. **تمدید رزرو فقط از طرف دفتر** (مجوز ویرایش سفارش)، نه مشتری.
- رزرو منقضی ← پیش‌پرداخت سوخت می‌شود و ماه‌ها خودکار آزاد می‌شوند؛ سپس صف «اطلاع بده» (هر ساعت یک نفر) پیشنهاد می‌گیرد.
- ورود دادهٔ رسانه‌ها از پنل، با نقش «سرپرست رسانه‌های محیطی»؛ ورود گروهی از اکسل با پیش‌نمایش.

## وضعیت
| بخش | وضعیت |
|---|---|
| دامنه: تقویم مالی، قواعد اسلات، صف انتظار، قواعد شیت اکسل | نوشته و تست‌شده (۴ تست گروهی) |
| جدول‌ها (رسانه، اسلات، صف)، قفل/رزرو/قطعی اتمیک، آزادسازی ساعتی، API فهرست/تقویم/نگه‌داشتن/اطلاع‌بده، ثبت نوع خط و قیمت‌گذاری سمت سرور | نوشته؛ فقط بررسی نحو؛ **روی وردپرس واقعی اجرا نشده** |
| صفحهٔ مدیریت رسانه‌ها + ورود از اکسل با پیش‌نمایش | بعدی |
| صفحهٔ رسانه، نقشه (نشان)، تقویم و سبد در المنتور | نیازمند سایت واقعی |
| مزایده، گزارش‌ها | فازهای بعدی |

## باز / نیازمند تصمیم
- بین ثبت سفارش اجاره و ثبت چک توسط دفتر، ماه‌ها نگه داشته نمی‌شوند (قفل فقط ۱۵ دقیقه است). اگر دفتر دیر ثبت کند ممکن است ماه آزاد شود؛ مالک تأیید کند یا مهلت دیگری تعیین کند.
- تطبیق ستون‌ها با فایل اکسل واقعی مبارکه (قواعد در `MediaSheetRules`).
